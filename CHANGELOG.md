## [1.0.0] - 2026-09-17
### Added
- The Kanvas scaffold: instruction files for `landing/`, `client/` and `server/`, plus seed data and an API contract.
- 13 JavaScript labs with 300+ Mocha tests (`labs/`), stretch suites, and two browser playgrounds.
- 10 phase guides, 48 concept primers, interview banks, machine-coding prompts, a system-design walkthrough, and a debugging lab.
- Three learning tracks (7-day intensive, 4-week standard, 8-week part-time) and a progress tracker.
- The AI tutor layer: `CLAUDE.md`, `AGENTS.md`, and six Claude Code skills (`/explain`, `/hint`, `/review`, `/quiz`, `/progress`, `/unstuck`).
- Repo health check (`tools/verify-scaffold.mjs`) and its GitHub Actions workflow for maintainers.
